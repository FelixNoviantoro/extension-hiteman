hiTeman Automation Recorder

* Data rekaman akan tersimpan di Chrome Storage dan dapat diakses dari hiTeman Application.

Cara Penggunaan:

  1. Masukkan URL website yang ingin direkam
  2. Klik "Mulai Rekam"
  3. Website akan terbuka di tab baru dengan panel kontrol
  4. Klik "Stop & Download" untuk menyimpan data
  5. Data akan tersimpan di Chrome Storage
